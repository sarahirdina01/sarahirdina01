### `> mission_brief`

EcoTrack is a centralized Android mobile application designed to support
campus recycling and thrift activities.

Students can submit recycling activities with photographic evidence,
earn reward points, participate in faculty recycling competitions,
track recycling history and use a built-in thrift marketplace.

Administrators can verify recycling submissions, manage users and
competitions, monitor marketplace activity and view platform analytics.

<br/>

### ⚡ `FEATURE_UNLOCKS`

- ♻️ Recycling submission with photographic evidence
- 🧠 Intelligent recycling evaluation using MRDE
- 🏆 Faculty recycling competitions
- ⭐ Reward points
- 📊 Recycling history
- 🥇 Faculty leaderboard
- 🛍️ Student thrift marketplace
- 💬 Buyer and seller communication
- 💳 Secure Stripe checkout
- 🧾 Transaction history
- ⭐ Seller rating system
- 👥 User management
- ✅ Administrator recycling verification
- 🏆 Competition management
- 📈 Administrator analytics

<br/>

### 🧠 `THE_CORE_ENGINE // MRDE`

The heart of EcoTrack is its:

## Multi-Layered Rule-Based Decision Engine

Instead of relying entirely on manual recycling verification, MRDE
evaluates recycling submissions using recyclable knowledge,
weight references and predefined rules.
